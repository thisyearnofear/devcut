# DevCut × x402

Pay-per-job API for Challenge Cut, Submit Ready, and hero shot packs.

## Endpoints (BFF, proxied at `/api/x402/*`)

| Method | Path | Auth |
| --- | --- | --- |
| GET | `/api/x402/catalog` | free |
| GET | `/api/x402/openapi.json` | free |
| POST | `/api/x402/jobs/{sku}` | **402** until `PAYMENT-SIGNATURE` |
| GET | `/api/x402/unlock/verify?token=` | free (validates unlock) |

SKUs: `challenge_film` ($2), `submission_polish` ($1), `hero_shot_pack` ($0.50), `product_launch` ($1.50 — polished founder/PM demo cut, door `product`).

## Agent flow

```bash
# 1. Discover
curl -s http://localhost:4010/api/x402/catalog | jq

# 2. Challenge (expect HTTP 402 + PAYMENT-REQUIRED header)
curl -i -X POST http://localhost:4010/api/x402/jobs/challenge_film \
  -H 'content-type: application/json' \
  -d '{"brief":"Builders must use Genblaze + B2…"}'

# 3. Settle — demo mode (default X402_MODE=demo)
curl -i -X POST http://localhost:4010/api/x402/jobs/challenge_film \
  -H 'content-type: application/json' \
  -H 'PAYMENT-SIGNATURE: demo' \
  -d '{"brief":"Builders must use Genblaze + B2…"}'
# → { job_id, unlock_token, canvas_path, mode_prompt }

# 4. Open canvas_path (or inject mode_prompt into the director agent)
```

## Modes

| `X402_MODE` | Behavior |
| --- | --- |
| `demo` (default) | Protocol-shaped 402s; accept `PAYMENT-SIGNATURE: demo` after challenge |
| `live` | Verify + settle via `FACILITATOR_URL` (e.g. CDP facilitator) |

Env: see root `.env.example` (`X402_PAY_TO`, `X402_NETWORK`, `FACILITATOR_URL`, `X402_UNLOCK_SECRET`).

## Product surface

Landing / canvas **Agent** door → SKU pick → brief → **Start job** (demo settle) → Open canvas.
Integrator tools (402 probe, curl snippets, OpenAPI) stay collapsed under “Show integrator tools”.
Paid unlock shows `x402 · {sku}` on the canvas header and auto-starts the job prompt.
After stitch, the same HyperFrames kit attaches as on human doors ([`hyperframes.md`](./hyperframes.md)).
